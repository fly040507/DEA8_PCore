## 第二阶段更新：实际 QK/PV 与 Attention 集成

### B 输入的临时边界

当前矩阵引擎接收的是 PCore 内部规范化列流，而非已确认的 GCore KVB 协议：
每个 Tile 依次发送 n=0..15，每个条目为 B[k=0..15,n] 和 E_stat[n]。
`dea8_tile_columns` 用两个 272-byte 暂存槽将列转为 PE 行加载，合计 544 byte 加控制寄存器。
这是新增的传输暂存，不是 PE 之外另一套驻留 W_BANK，也不是对 HBM MCU 缓冲的修改。
它尚属接入实现方案，不能擅自认为已成为 GCore 的冻结布局。

QK 时每条目是一名 key 的 16 个 feature；PV 时每条目是一名输出 feature 的 16 个 key。
PV 的后者顺序与旧文档“KVB 特征块”措辞需要进一步确认。
如果实际 V 条目是同一 key 的 16 个 feature，不能把其单个 scale 随意复制给 16 个输出列；
需要先明确 V 的 E_v 传输约定，再做 Adapter。

首 Tile 的 16 条入口数据收集发生在 16 拍 Bank Load 之前。因此 832 拍只统计 Load+Compute，
不能宣称从 job_valid 到 done 的整个时间都是 832 拍。正式 KVB 前端可在许可的传输缓存中预取，
但不能跨 Block 提前加载 PE Stationary Bank。

## 存储接口契约

`deq_reserved[2:0]` 对应 FACC_A、FACC_B、OACC，属于外部 Controller 的整 Job 预约。
必须在第一笔 DEQACC 访问前生效，到最后 L4 Commit 完成后才能释放。
Fabric 不自行产生预约，也不实现完整的生产/消费代际 scoreboard。
预约给 DEQACC 的 Bank 对 VPU 返回 ready=0；DEQACC 没有 backpressure。
所有权切换前还必须确认旧 VPU Job 的最后一次写入已经完成。

不同 Bank 可同时服务，例如 DEQACC 访问 OACC、VPU 读取 FACC_A；或者 DEQACC 写 FACC_B、VPU 读 FACC_A。
同 Bank 同地址读写为非法，沿用原先不依赖 RAM read-during-write 模式的约束。
VPU 读请求握手后固定一拍返回，响应不带 ready，调用者须提前预留接收能力。

QK standalone 保持原有 `facc_rd_en` 接口，不增加 ready；测试调用者不得请求当前预约 Bank。
正式 VPU 集成使用 Fabric 的 valid/ready 端口，而非 standalone 的受限读口。

SBUF/PBUF 提供同步一拍响应，读写 Bank 和行地址分别指定。
同 Bank 的生产/消费交叠由断言拒绝；这里也不替代 Controller 的 Bank generation 管理。

## 调度接口契约

三个计算域均采用：cmd valid/ready 接受，done valid/ready 完成。
命令与完成各有完整操作类型、block/head/epoch 和 Bank 选择。
目前返回原命令记录作为完成记录以校验上下文；这不是旧全局 VOP 编码。
不同本地存储在 VPU Job 中分别保留 Bank 字段，不把多个资源永久绑定成一个端口。
当前调度器采用 block 奇偶映射这些 Bank；完成屏障保证使用完再复用。

矩阵命令顺序：

```text
QK0
QK1 || POST0
PV0 || POST1
QK2 || SCALE1
PV1 || POST2
...
QK54 || SCALE53
PV53 || POST54
SCALE54
PV54
RECIP
AFIN
```

POST = VPU_QK_POST -> SFU_ALPHA_EXP -> SFU_P_EXP 与 VPU_P_POST 联合完成。
先启动 VPU P 消费者，再启动 SFU P 生产者。SFU 完成不代表 PBUF 已经写完。
Matrix done 必须由真实最后 L4 Commit 产生；VPU done 必须表示最终结果写入完成。
完成响应返回错误上下文会触发断言。整个 Attention done 保持到调用者接受。
该调度器尚未与 Matrix Engine、Fabric、标量存储和真实壳子连成 PCore Top。

832 是加载加矩阵计算的周期预算，不是接口握手到 done 的硬编码倒计时。
调度器等待实际完成，不靠 832、26、408、816 的定时器猜测写回结束。
测试中的带延迟执行器只是控制模型，不产生真实浮点结果或存储副作用。
