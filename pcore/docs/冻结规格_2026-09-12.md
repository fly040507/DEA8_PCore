# 2026-09-12 当前基线

来源：本次用户上传的 README.docx。文档前半部分仍有旧pipe[0]措辞时，以后半部分第8～17节明确的替换条款为准。
本文件取代2026-09-11冻结规格以及旧MXU/Loader说明。DEQACC和Attention尚未实现的部分仍按目标标注。

## HBM与W_Loader

HBM为256bit，beat0～7承载256B矩阵数据；beat8低128bit为16个E8M0，高128bit保留忽略。有效272B，物理288B。
数据beat低128bit先入FIFO，对应B的偶数K行；高128bit后入FIFO，对应奇数K行。128bit字内低字节对应lane0。
WFIFO_DATA=128bit×512；WFIFO_SCALE=128bit×32。E_stat[n]对应输出列n的16个K元素。

统一模块 dea8_w_loader 包含HBM Fetch、两个FIFO和Bank Load。旧dea8_weight_loader与dea8_mcu_weight_path已移除。
启动加载前必须已有16个数据entry、1个scale entry和NULL bank。
首拍同时pop数据和scale；后15拍只pop数据。启动后持续16拍，不受bank_load_enable随后变化影响。
bank_load_enable只准许新的Bank Load；HBM到FIFO的预取独立进行，可跨block。

## 状态唯一所有权

只有W_Loader写bank_state、active_bank和load_bank寄存器。
四状态：NULL、LOAD、READY、ACTIVE。最多一个LOAD、一个ACTIVE。
首次没有ACTIVE时，第16个写权重沿直接LOAD->ACTIVE，同时产生bank_activate/new_active_bank。
中间Tile加载后先READY；当前Tile最后行真正进入PE乘法的tile_last_mul_fire沿，旧ACTIVE->NULL，新READY->ACTIVE。
事件是时钟沿前的组合事件，MXU和Loader在同一沿采样，不额外寄存事件造成切换空拍。

## MXU输入边界与旁带

| 寄存器 | 含义 |
| --- | --- |
| Q_ACT_REG | 16个signed INT8激活 |
| E_STREAM_REG | 当前A组的8bit E8M0编码 |
| ACT_TAG_REG | 当前A组完整tag |
| ACT_VALID_REG | 当前A组有效标记 |
| E_STAT_ACTIVE_REG | 当前ACTIVE Tile的16个E8M0 |

四个A侧寄存器同沿锁存。E_STAT_ACTIVE_REG只在bank_activate沿从目标E_STAT_BANK更新。
不再存在sideband_pipe[0]。
Stage0输入锁存；Stage1乘法并把E_STREAM_REG、E_STAT_ACTIVE_REG、ACT_TAG_REG及valid复制到pipe[1]。
Stage2～5分别为四级加法树和pipe[2]～pipe[5]；第四级直接写Psum_out_reg。
每个有效乘法都复制E_stat，不只是每Tile复制一次。

切换沿PE/pipe[1]使用沿前旧bank、旧scale和旧A末行；该沿同时锁存新A首行并更新ACTIVE及E_STAT_ACTIVE_REG。
所以旧末行不会混入新scale，新首行在下一乘法沿使用新权重。

## 连续执行与周期

每Tile51个连续有效乘法，row0～50。无局部stall，也未实现运行中全局freeze。
req_ready只表达输入边界是否允许接收；上游必须在row0启动前保证后续50组激活供应。中断将触发仿真断言。
rsp_ready只能用于检查已经预留的DEQACC容量，不能停住MXU。
首Tile第16个加载沿接收row0；下一沿锁存首个乘积。
一个block首16拍加载+16×51乘法=832拍。末Tile期间不能启动下一block的Bank Load，上游sequencer以bank_load_enable控制。
资源未预留时可在Tile边界等待；832拍是数据已供给时的预算，不包括HBM不足等待和最终流水写回。
六级指六个寄存阶段：E0接受输入，E5后输出有效，共五个沿间隔。下游在后续采样沿接收，避免把“阶段数”和“沿间隔”混为一谈。

## DEQACC与Attention目标

DEQACC五级L0符号/绝对值、L1初步FP32、L2完成反量化、L3 FACC累加或OACC+PV、L4写回。
DEQACC已补充真实算术和写回RTL，MXU与DEQACC在测试台连接验证；生产级Sequencer与完整Attention Top仍未接入。实现状态以IMPLEMENTATION_STATUS.md为准，不能把仿真通过等同于综合时序签核。

Attention保留55次QK/55次PV，每block832拍目标。QK完成写FACC后，经VPU生成masked SBUF、m_new及aa=m_old-m_new。
m与aa各一代51个FP32；alpha两代。SFU先26个输入拍计算alpha，再408个输入拍计算P。
l使用量化前FP32 P更新；P再量化供PV。O_b=alpha_b*O_(b-1)+PV_b。
最后SCALE54提交、PV54提交、SFU倒数、VPU最终乘法顺序执行。
PPT的启动序列QK0、QK1、PV0保留；“交替”不应覆盖启动依赖。
